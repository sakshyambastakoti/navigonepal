Architectural Tip: Moving to Production

Upgrading from LocalStorage Override
Currently, toggling maintenance mode saves the state to localStorage.setItem('navigo-maintenance-mode') in the current browser. This is perfect for local testing and validation.

For a live deployment where all users are toggled globally:
1. Change the check in js/maintenance.js to run a fast fetch() call targeting a lightweight JSON configuration, a serverless cloud function, or a CDN KV store.
2. Connect this toggle switch to an API endpoint (e.g. via an authenticated POST request) that modifies that remote database/file state globally.
